Start the live iPhone mirror. Run this with the Bash tool using run_in_background: `python3 "${CLAUDE_PLUGIN_ROOT:-$HOME/iPhoneUse}/scripts/mirror.py"`. Then tell the user the mirror is at http://127.0.0.1:8765 (VS Code users: Cmd+Shift+P, "Simple Browser: Show"). Do nothing else.
